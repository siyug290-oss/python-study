## 今天的闭环：lambda

**昨天**：看到 `sorted(counts.items(), key=lambda x: x[1], reverse=True)` 完全看不懂，
判断"这个超纲了，放到明天"。

**今天**：学完函数之后，自己写出了等价的两个版本，跑在一起对比，确认结果完全相同。

```python
def take_second(x):        # 写法一：有名字的函数
    return x[1]

sorted(counts.items(), key=take_second, reverse=True)
sorted(counts.items(), key=lambda x: x[1], reverse=True)   # 写法二：等价
```

**两个关键理解：**

1. `lambda x: x[1]` 就是一个函数——只不过没起名字，一行写完。
2. **`key=` 要的不是一个值，是一个函数。** `sorted` 拿到函数后，会把每个元素
   喂给它，用**返回的结果**来比大小。

**更重要的收获不是语法，是方法**：昨天判断"先放一放，等学完前置知识再来"，
今天回来一遍就通了。**能分清"我再想想就能懂"和"我得先学别的东西"，
比硬啃三小时有用得多。**
